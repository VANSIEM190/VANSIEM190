# 👨‍💻 Van'siem — Développeur Fullstack

> Développeur fullstack avec 4 ans d'expérience, spécialisé en React, React Native et Node.js. Je conçois des applications web et mobile complètes, du frontend à la base de données.

---

### 👤 À propos

Je suis Van'siem, développeur fullstack et fondateur de la chaîne **ClipNestDev**, où je partage des tutoriels et des retours d'expérience sur le développement web, mobile et l'IA appliquée au code.

Sur le plan technique, je travaille principalement dans l'écosystème React (web et mobile), avec TypeScript et Prisma côté backend. J'aime autant l'aspect ingénierie (architecture, fiabilité du code) que le design d'interface.

### 🎯 Ce que je recherche

Je suis ouvert aux opportunités de collaboration, missions freelance ou postes en développement fullstack — particulièrement sur des projets React / React Native / Node.js.
